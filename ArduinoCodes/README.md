### arduino_basic
- 아두이노 연산 테스트
- 시리얼 입출력 테스트
- LED 제어

### ball_switch 
- ball 스위치 제어 (작은 공이 들어있어 평소에는 연결되어 있다가 기울이게되면 공이 굴러가 스위치가 off 되는 제품)

### rgb_led
- 빛의 3원색 이용 LED 색 제어

### tact_switch
- 택트 스위치 제어 (버튼식 스위치)
- 스위치1 누를시 LED 점등, count 증가, 스위치2 누를시 LED 점등, count 감소

### variable_resistor
- 가변 저항 제어
- map(변환할 수, 현재 범위의 하한값, 현재 범위의 상한값, 목표 범위의 하한 값, 목표 범위의 상한값)
